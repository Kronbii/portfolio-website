# Topic hub briefs

Topic hubs exist to connect related evidence, not to manufacture expertise pages around isolated keywords. A topic page should render only when it has at least two ready items.

## Computer vision

- Slug: `computer-vision`
- Plain-language definition: engineering systems that extract useful structure from images or video.
- Ready evidence: 360° spherical stitching; thermal super-resolution; autonomous race car; fine-crack tracing.
- Related but review-only: OmniSign; runway-inspection UAV; emotion-recognition prototype.
- Questions the page should answer: What computer-vision systems has Rami Kronbi built? Which run in real time or on edge hardware? Which projects expose reusable code?
