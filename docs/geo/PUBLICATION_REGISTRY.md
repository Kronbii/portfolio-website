## Status vocabulary

- `live-verified` — URL and metadata checked during the current audit.
- `site-declared` — represented in the current portfolio but not rechecked live in this registry.
- `needs-reconciliation` — factual, authorship, canonical, or disclosure conflict exists.
- `candidate` — profile or source may contain publications not yet inventoried.
- `archived` — intentionally retained as history but not part of the active content strategy.

## Canonicalization strategy

For future approved technical articles:

1. Publish the complete ramikronbi.com version first.
2. Confirm that the canonical page is live, indexable, and technically correct.
3. Adapt the platform version without changing facts or inventing personal narrative.
4. Use the platform's canonical URL mechanism when available.
5. Link visibly to the canonical article, project record, repository or demo, and relevant topic hub.
6. Record publication dates and external URLs here.
7. Avoid mass publication that makes the content system appear automated or repetitive.
